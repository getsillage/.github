# Contributing to Sillage

Thank you for helping improve Sillage. Product code, documentation, architecture, and release work belong in [`getsillage/sillage`](https://github.com/getsillage/sillage); website work belongs in [`getsillage/getsillage.github.io`](https://github.com/getsillage/getsillage.github.io).

Before opening a change:

1. Read the target repository's README and contributor instructions.
2. Keep proposals within Sillage's private, self-hosted, single-user scope.
3. Search existing issues and use the repository's issue forms when available.
4. Include tests and documentation for behavior, configuration, contract, or user-facing changes.
5. Use synthetic data only; never submit private records, credentials, database files, or production logs.

The complete engineering workflow is maintained in the [Sillage contributing guide](https://github.com/getsillage/sillage/blob/main/CONTRIBUTING.md). Public copy and visual work should also follow the [brand and content guide](BRAND.md).
