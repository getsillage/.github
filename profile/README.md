# Sillage

Sillage is a self-hosted private journal and AI reflection space.

- Repository: https://github.com/getsillage/sillage
- Releases: https://github.com/getsillage/sillage/releases
- Documentation: https://github.com/getsillage/sillage/tree/main/docs
- License: MIT

Sillage is designed for single-person use. Your notes, attachments, AI profiles,
and runtime data stay in your self-hosted instance.
