# Code of Conduct

All Sillage organization spaces follow the [Contributor Covenant Code of Conduct](https://github.com/getsillage/sillage/blob/main/CODE_OF_CONDUCT.md), version 2.1.

We expect empathetic, respectful, constructive participation and do not tolerate harassment, disclosure of private information, personal attacks, or other unprofessional behavior.

Report conduct concerns privately through [GitHub Private Vulnerability Reporting](https://github.com/getsillage/sillage/security/advisories/new) and prefix the title with `[Conduct]`. Do not include conduct reports in public issues.
