# Support

Sillage is a self-hosted open-source project without an official hosted service or support SLA. Help is provided on a best-effort basis.

Before asking for help, read the [documentation hub](https://github.com/getsillage/sillage/tree/main/docs), identify your release or commit, search existing issues, and remove all records, attachment names, hostnames, credentials, tokens, and other sensitive data.

- [Report a reproducible bug](https://github.com/getsillage/sillage/issues/new?template=bug_report.yml)
- [Request an in-scope improvement](https://github.com/getsillage/sillage/issues/new?template=feature_request.yml)
- [Ask a setup or usage question](https://github.com/getsillage/sillage/issues/new?template=question.yml)
- [Report a vulnerability privately](https://github.com/getsillage/sillage/security/advisories/new)

See the canonical [support guide](https://github.com/getsillage/sillage/blob/main/SUPPORT.md) for support boundaries and recovery guidance.
